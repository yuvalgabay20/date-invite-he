# הזמנה לדייט

מיני־אתר בעברית עם שאלה אחת ותשובה אחת אפשרית.

**[לצפייה באתר](https://yuvalgabay20.github.io/date-invite-he/)**

## מה קורה שם

שלושה מסכים ותוצאה. בפתיחה נשאלת השאלה, ולידה כפתור "לא" שמתחמק מהעכבר, קופץ הצידה וחוזר למקומו — ומתחמק שוב בכל פעם שמכוונים עליו. אחרי "כן" בוחרים תאריך ושעה מתוך השבועיים הקרובים, ואז מה אוכלים. שני השלבים האלה מכוונים תמיד לתשובה אחת: התוכנית חוזרת ל"הפתעה", והאוכל חוזר ל"שיובל יבחר", עם עקיצה מתחלפת בכל ניסיון. בסוף — קונפטי, כרטיס סיכום, וכפתור שמעביר את הפרטים בוואטסאפ.

## התאמה אישית

כל הפרמטרים אופציונליים, והאתר עובד גם בלעדיהם:

```
index.html?to=דנה&from=יובל&g=f&phone=972501234567
```

| פרמטר | מה הוא עושה |
|---|---|
| `to` | שם הנמענת, נכנס לכותרות |
| `from` | השם שלך — מופיע באפשרות האוכל ובעקיצות (ברירת מחדל: יובל) |
| `g` | `f` לנקבה (ברירת מחדל), `m` מחליף את כל הניסוחים ללשון זכר |
| `phone` | מספר לקישור הוואטסאפ, בפורמט בינלאומי בלי `+` |

## טכני

קובץ אחד, בלי build ובלי תלויות. הכל בתוך `index.html` — הסגנון, הלוגיקה, הקונפטי על קנבס, ושני האיורים כ־SVG וקטורי. הפונטים העבריים (Frank Ruhl Libre ו־Assistant) נטענים מ־Google Fonts, עם נפילה לפונטי מערכת.

RTL מלא, רספונסיבי מ־375px, ניווט מקלדת מלא, וכיבוד `prefers-reduced-motion` שמשבית את כל התנועה.
